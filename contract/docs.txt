# is from the top of the folder, and the head every page says. Written by a test, never by
# hand: a page added is written down by
#   WRITE_DOCS=1 cargo test -p api the_docs
# and one taken away, which somebody may link to, only by saying why:
#   BREAK_DOCS="why" cargo test -p api the_docs
# which keeps the reason in docs-broken.txt.
